# 庭のキャンバス｜Garden Canvas

植えて、眺めて、入れ替えて。理想の庭を見つけよう。

公開URL: https://nature-wx-lab.github.io/garden-canvas/

## 初回公開 0.1 の範囲

家庭向けの庭プランニングツールの初期試作版です。3Dの同じ庭を自由に回転・拡大し、長方形・L字・自由な多角形の庭に植物を配置、移動、交換できます。最大100株、庭の幅・奥行き2〜30m。選択は画面上でも一覧からでも可能です。取り消しは直前30回まで。JSONファイルの保存・復元に対応します。

落葉樹・常緑樹・花の宿根草・グラスの4種類は、コードで描く配置用の模式モデルです。実在する種・品種のカタログではありません。表示寸法は利用者が設定する値であり、生育値ではありません。季節スライダーは一般化した見た目のイメージです。特定品種の開花期・落葉期・成長量を予測しません。

完成形として、品種別の成長、株の充実、維持したい樹冠と剪定、年間作業時間、購入予算、同条件のプラン比較、より写実的な植物、任意のAIアシストを目指します。初回では未実装です。年次成長の仮係数・架空価格・未検証の剪定頻度を実データとして提供しません。

## 操作

- 種類を選んで庭をクリックすると配置できます。「眺める・選ぶ」で視点操作に戻ります。
- 植物を選択すると、寸法・座標・種類を編集できます。「場所を移す」で庭の移動先を指定できます。種類の交換は同じ位置・同じ寸法の配置比較です。
- 自由な庭は上面で角を順に指定します。交差する形と1m²未満の形は受け付けません。外側に植物が残る変更は拒否し、勝手に削除しません。
- マウスドラッグ／1本指で回転、ホイール／2本指で拡大・移動。視点ボタンと拡大縮小ボタンも使えます。キャンバスにフォーカスした状態の左右矢印で回転、Escapeで編集モードを解除します。
- 保存は端末へのJSON書き出しのみです。読込は100KB・100株・16頂点までで、データ型・範囲・形状・未知の項目を検査し、不正なファイルは庭を変更せず拒否します。

## プライバシーと公開境界

庭は画面のメモリーだけに保持し、再読込するとサンプルに戻ります。住所・位置情報・写真・ログインは取得しません。庭を共有URL、サーバー、アクセス解析、外部AIへ送る機能はありません。保存ファイルは利用者自身で管理してください。配信元GitHubには通常のHTTPアクセス情報が届きます。

描画ライブラリは同梱し、外部CDN・フォント・計測タグは読み込みません。Content Security Policyのmeta指定で外部通信、埋込み、フォーム送信等を制限します。GitHub Pagesではアプリが任意のHTTPセキュリティヘッダーを設定できず、metaはHTTPヘッダーの完全な代替ではありません。フレーム埋込み制限はこの初期配信方式では保証しません。秘密情報やクラウド保存を追加する場合は別途配信・認証設計を行います。

新規の独立リポジトリから配信します。サイトファイルは `site/` 内の10ファイルに限定し、文書、検査、Git管理情報はPages artifactに入れません。公開ソース17ファイルと全到達可能コミットのファイル・氏名・メール・メッセージを `scripts/release_check.py` で検査します。許可外のファイル・個人メール形式・ローカルパス・主要な資格情報形式は配信を停止します。静的検査だけで未知の秘密や全種類の個人情報を完全検出できるものではなく、変更差分の目視確認も必要です。

コミットのauthorとcommitterには `nature-wx-lab` と確認済みGitHub noreplyメールを使い、個人のGit既定値を継承しません。Actionsは検査時に読み取り権限だけ、配信ジョブにPages用の権限だけを付与し、公開リポジトリの書換えや独自の長期認証情報を必要としません。Actionsは固定したcommitを参照します。

## 開発と検証

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory site
node --test scripts/model.test.mjs
python3 scripts/release_check.py
```

変更はこのツール専用リポジトリで作成し、許可ファイルだけを明示的にstageします。検査後のmainへのpushでGitHub Actionsが検査とPages配信を行います。公開更新の依頼を確認してからpushしてください。ローカルと公開の同じ機能を操作し、サイト10ファイルのSHA-256・配信対象commit・Content-Type・404を照合します。
